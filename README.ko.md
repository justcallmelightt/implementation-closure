# Implementation Closure

Implementation Closure는 여러 상태에서 동작해야 하거나, 이전에 실패했거나, 완료 여부를 확신하기 어려운 기능 구현·버그 수정을 끝까지 확인하기 위한 [Agent Skill](SKILL.md)입니다.

## 프로젝트에서 사용하기

이 디렉터리를 에이전트의 Skill 위치에 `implementation-closure`라는 이름으로 설치하세요. Codex에서는 `~/.codex/skills/implementation-closure/SKILL.md`에 위치합니다. 구체적인 구현이나 수정 작업을 요청하면 관련 상황에서 사용할 수 있고, `$implementation-closure`로 직접 지정할 수도 있습니다. 단독 리뷰나 상태 질문에는 적용하지 않습니다.

## 구현과 완료 사이의 간격 줄이기

이 Skill은 기대한 동작과 실제 결과를 구분하고, 관련 경로를 확인해 범위에 맞게 수정한 뒤, 원래 실패한 사례와 인접한 상태를 다시 확인하도록 안내합니다. 결과를 보고할 때 직접 관찰한 내용, 자동 검사 결과, 확인하지 못한 내용을 나눕니다. 배포·push·무관한 수정 권한을 부여하지는 않습니다.

예를 들어 `0`은 보이지만 `1`에서 잘리고 `2`에서 사라지는 롤링 카운터라면 `0 → 1 → 2`와 `/ 6` 같은 분모의 정렬을 함께 확인해야 합니다. 코드 테스트 통과만으로 화면의 실제 동작까지 증명되지는 않습니다. 이 사례는 검증 기준의 예시이며, Skill의 효과가 입증됐다는 뜻은 아닙니다.

## 효과 검증

모델과 실행 환경이 비슷한 구현 요청에서 Skill을 사용한 경우와 사용하지 않은 경우를 비교하세요. 원래 실패 사례와 인접 상태의 확인 여부, 사용자의 재수정 요청 여부, 추가 도구·토큰 비용을 기록합니다. 재요청 감소 효과는 아직 검증되지 않았습니다.
